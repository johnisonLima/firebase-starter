# 03 — Tipografia

O Firebase Starter utiliza a configuração tipográfica fornecida
pela base Tailwind CSS e Spartan, mantendo uma abordagem simples
e consistente para a hierarquia textual da aplicação.

A fonte padrão utiliza a família `sans-serif`, priorizando as fontes
nativas disponíveis no sistema operacional.

## 03.1 — Família tipográfica

A família padrão é definida pelo token `--font-sans`:

```text
-apple-system
BlinkMacSystemFont
Segoe UI
Roboto
Helvetica Neue
Arial
Noto Sans
sans-serif

O Firebase Starter não cria uma escala tipográfica paralela ao Tailwind. A escala fornecida pelo Tailwind é a referência padrão do projeto.
