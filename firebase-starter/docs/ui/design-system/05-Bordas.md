# 05 — Bordas e Radius

O Firebase Starter utiliza as convenções de bordas e radius
fornecidas pelo Tailwind CSS como base, complementadas pelos
tokens semânticos definidos pelo tema.

## 05.1 — Bordas

A borda padrão dos componentes utiliza espessura de `1px` e a cor
definida pelo token `--border`.

```scss
border: 1px solid var(--border);
